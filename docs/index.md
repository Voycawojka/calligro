# Calligro Tutorial

Calligro is a free, open source bitmap font generator.
It produces fonts in the BMFont format, which is supported by most game engines and frameworks.

## How it works

1. Generate a Calligro template (which is a .png or .aseprite image)
2. Draw your characters in the template in any graphics editor
3. Load the filled template back into Calligro and save a bitmap font
