# Web App vs Desktop App

Calligro comes in two versions with the same core features.

- **[Web app](https://calligro.ideasalmanac.com/webapp.html){target="_self"}**: runs in your browser (chromium-based recommended)
- **[Desktop app](https://voycawojka.itch.io/calligro)**: download from itch.io for Windows and Linux.

Both versions run everything on your computer.
Your files are not uploaded to any servers (even in the web version).

## Differences

For technical reasons, when using the [pre-fill](/guide/template-settings#pre-fill-with-a-ttf-font) option in the web app, only a limited set of commonly used fonts is available. 
The desktop app allows you to choose any font installed on your system.
