# UI Overview

Create or open a project to get started.

When a project is open, the UI is divided into three sections.
In general, the left section is relevant only before exporting a template.
After drawing your characters and importing the template back, you'll work with the right section.
The middle one is a preview relevant the whole time.

- **[Template Settings](/guide/template-settings)**: defines the character set, size, and other properties that affect what you'll be drawing.
- **Preview**: shows how the font will look with the current settings.
- **[Font Settings](/guide/spacing-and-kerning)**: options that can be adjusted after drawing the characters.
